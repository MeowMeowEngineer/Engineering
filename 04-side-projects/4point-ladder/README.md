# 4점 사다리 (수능 수학 4점 훈련 앱, 프로토타입)

중하위권 수험생이 수능 수학 4점 문제를 못 푸는 이유는 개념 하나를 몰라서라기보다, 한 문제에 개념 3~5개가 섞여 있어 어디서 막혔는지 모르기 때문입니다. 4점 사다리는 목표 4점 문제 하나를 개념 단위로 쪼개고, 약한 개념만 골라 목표 시간 안에 풀 때까지 반복시킨 뒤, 숫자만 바꾼 쌍둥이 문제로 도달 여부를 확인합니다.

## 학습 흐름

1. **목표 문제**: 4점 유형 문제 하나를 고릅니다. 바로 풀어 볼 수도 있습니다.
2. **개념 진단**: 문제에 섞인 개념마다 짧은 문제를 하나씩 풉니다. 틀리면 `약함`, 맞혔지만 목표 시간을 넘기면 `느림`으로 표시합니다.
3. **개념 훈련**: 약함·느림 개념만 반복합니다. 문제는 매번 숫자를 바꿔 새로 만듭니다. 목표 시간 안에 3문제 연속으로 맞히면 `숙달`입니다. 두 번 연속 틀리면 그 아래 개념(예: 접선의 방정식 → 미분계수 계산)부터 훈련하도록 안내합니다.
4. **연결 풀이**: 원래 문제를 단계별 소문항으로 나눠, 숙달한 개념을 순서대로 이어 붙입니다. 첫 오답에는 힌트를 주고 한 번 더 풀게 합니다.
5. **쌍둥이 실전**: 같은 유형, 다른 숫자의 문제를 힌트 없이 5분 안에 풉니다. 맞힌 최고 기록을 `도달` 시간으로 남깁니다.

각 개념 카드에는 문제 속 어떤 표현이 그 개념을 부르는지(`문제 속 단서`)를 함께 적었습니다. 예를 들어 "점 O에서의 접선"이 보이면 `f(x) − l(x)`가 `x²`을 인수로 가진다는 것을 떠올리도록 합니다.

## 지금 들어 있는 내용

| 목표 문제 | 과목 | 섞인 개념 |
|---|---|---|
| 접선과 넓이 | 수학Ⅱ 미분·적분 | 접선의 방정식, 접점은 중근, 두 그래프 사이 넓이, 다항함수 정적분 |
| 절댓값이 같은 두 항 | 수학Ⅰ 수열 | 절댓값이 같은 두 항, 등차중항, 일반항, 절댓값이 있는 합 |
| 역함수와 대칭 | 수학Ⅰ 지수·로그 | 역함수와 y=x 대칭, 대칭인 두 점 사이 거리, 밑 구하기, 로그 값 |
| 삼각방정식 해의 합 | 수학Ⅰ 삼각함수 | sin²+cos²=1 치환, 치환한 이차방정식, 특수각 방정식, 대칭으로 해의 합 |

- 개념은 목표 문제에 직접 쓰이는 16개와, 막힐 때 내려가는 아래 개념 2개(미분계수 계산, 등차수열의 합)를 합쳐 18개입니다.
- 문항은 이 앱을 위해 새로 만들었습니다. 기출 문항을 옮기지 않았습니다.
- 범위는 2027학년도 수능 공통과목(수학Ⅰ·Ⅱ)입니다. 2028학년도부터 바뀌는 과목에서도 이 단원들은 대수·미적분Ⅰ에 들어갑니다.

## 검증

- 숫자를 바꿔 문제를 만드는 코드 18종과 쌍둥이 문제 4종을 각각 수천 번 생성해, 답을 앱과 다른 방법으로 다시 계산해 대조했습니다(수치 적분, 근 전수 탐색, 수열 직접 합산, 밑 `a`를 촘촘히 바꿔 가며 교점 찾기). 불일치 0건.
- 역함수 문제는 단서 "(점 A의 x좌표가 B보다 작다)"가 없으면 `a = 2^(1/4)`도 답이 되는 것을 검증 중에 확인해, 단서를 문제에 넣었습니다.
- 휴대폰 폭(400px)에서 가로 스크롤과 콘솔 오류가 없는 것을 확인했습니다.

## 구조와 실행

- `index.html` 파일 하나입니다. 수식은 MathJax 3(cdnjs)로 그립니다.
- 학습 기록은 브라우저 `localStorage`에만 저장합니다. 다른 기기와 공유되지 않습니다.
- 문항과 개념은 `// ==CONTENT START==`와 `// ==CONTENT END==` 사이의 `CONCEPTS`, `TARGETS`에 있습니다. 목표 문제를 추가하려면 `TARGETS`에 문제·개념·단계·쌍둥이 생성 함수를 넣습니다.
