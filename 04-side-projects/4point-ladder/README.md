# 4점 사다리 (수능 고난도 문항 훈련 앱, 프로토타입)

지금은 수학만 들어 있고, 국어·영어·탐구로 넓힐 계획입니다([과목 확장 계획](#과목-확장-계획-국어영어탐구)).

중하위권 수험생이 수능 수학 4점 문제를 못 푸는 이유는 개념 하나를 몰라서라기보다, 한 문제에 개념 3~5개가 섞여 있어 어디서 막혔는지 모르기 때문입니다. 4점 사다리는 목표 4점 문제 하나를 개념 단위로 쪼개고, 약한 개념만 골라 목표 시간 안에 풀 때까지 반복시킨 뒤, 숫자만 바꾼 쌍둥이 문제로 도달 여부를 확인합니다.

## 학습 흐름

1. **목표 문제**: 4점 유형 문제 하나를 고릅니다. 바로 풀어 볼 수도 있습니다.
2. **개념 진단**: 문제에 섞인 개념마다 짧은 문제를 하나씩 풉니다. 틀리면 `약함`, 맞혔지만 목표 시간을 넘기면 `느림`으로 표시합니다.
3. **개념 훈련**: 약함·느림 개념만 반복합니다. 문제는 매번 숫자를 바꿔 새로 만듭니다. 목표 시간 안에 3문제 연속으로 맞히면 `숙달`입니다. 두 번 연속 틀리면 그 아래 개념(예: 접선의 방정식 → 미분계수 계산)부터 훈련하도록 안내합니다.
4. **연결 풀이**: 원래 문제를 단계별 소문항으로 나눠, 숙달한 개념을 순서대로 이어 붙입니다. 첫 오답에는 힌트를 주고 한 번 더 풀게 합니다.
5. **쌍둥이 실전**: 같은 유형, 다른 숫자의 문제를 힌트 없이 5분 안에 풉니다. 맞힌 최고 기록을 `도달` 시간으로 남깁니다.

각 개념 카드에는 문제 속 어떤 표현이 그 개념을 부르는지(`문제 속 단서`)를 함께 적었습니다. 예를 들어 "점 O에서의 접선"이 보이면 `f(x) − l(x)`가 `x²`을 인수로 가진다는 것을 떠올리도록 합니다.

| 목표 문제 | 과목 | 섞인 개념 |
|---|---|---|
| 접선과 넓이 | 수학Ⅱ 미분·적분 | 접선의 방정식, 접점은 중근, 두 그래프 사이 넓이, 다항함수 정적분 |
| 절댓값이 같은 두 항 | 수학Ⅰ 수열 | 절댓값이 같은 두 항, 등차중항, 일반항, 절댓값이 있는 합 |

| 넓이에서 외접원까지 | 수학Ⅰ 삼각함수 | 넓이로 각 구하기, 특수각의 삼각비, 코사인법칙, 사인법칙과 외접원 |

- 목표 문제는 10개, 개념은 40개입니다. 개념 중 미분계수 계산, 등차수열의 합처럼 목표 문제에 직접 나오지 않는 것은 막힐 때 내려가는 아래 개념입니다.
- 로그 부등식 문제는 난이도가 3점 수준이라 [3점]으로 표시했습니다. 나머지는 4점 유형을 목표로 만들었습니다.
- 문항은 이 앱을 위해 새로 만들었습니다. 기출 문항을 옮기지 않았습니다.
- 범위는 2027학년도 수능 공통과목(수학Ⅰ·Ⅱ)입니다. 2028학년도부터 바뀌는 과목에서도 이 단원들은 대수·미적분Ⅰ에 들어갑니다.

## 검증

- 개념 문제 생성 코드 40종은 각각 4,000번 생성해 답이 정수인지, 수식 표기가 깨지지 않는지 검사했습니다.
- 쌍둥이 문제 10종과 개념 문제 일부는 앱과 다른 방법으로 답을 다시 구해 대조했습니다(수치 적분, 근 전수 탐색, 수열 직접 합산, 첫째항 전수 탐색, 연립방정식으로 미지 함수 복원, 정수 x 직접 대입). 불일치 0건.
- 역함수 문제는 단서 "(점 A의 x좌표가 B보다 작다)"가 없으면 `a = 2^(1/4)`도 답이 되는 것을 검증 중에 확인해, 단서를 문제에 넣었습니다.
- 휴대폰 폭(400px)에서 가로 스크롤과 콘솔 오류가 없는 것을 확인했습니다.

## 구조와 실행

- `index.html` 파일 하나입니다. 수식은 MathJax 3(cdnjs)로 그립니다.
- 학습 기록은 브라우저 `localStorage`에만 저장합니다. 다른 기기와 공유되지 않습니다.
- 문항과 개념은 `// ==CONTENT START==`와 `// ==CONTENT END==` 사이의 `CONCEPTS`, `TARGETS`에 있습니다. 목표 문제를 추가하려면 `TARGETS`에 문제·개념·단계·쌍둥이 생성 함수를 넣습니다.

## 과목 확장 계획 (국어·영어·탐구)

학습 흐름(목표 문항 → 개념과 문제 속 단서 → 진단 → 약한 개념 반복 → 연결 풀이 → 쌍둥이 실전)은 과목이 바뀌어도 그대로 씁니다. 과목마다 달라지는 것은 문항을 무엇으로 쪼개는지와 반복 문제를 어떻게 만드는지입니다.

| 과목 | 먼저 다룰 고난도 문항 | 쪼개는 단위 | 반복 문제 만드는 법 |
|---|---|---|---|
| 수학 (완료) | 4점 단답형 | 개념·공식 | 숫자를 바꿔 자동 생성 |
| 탐구 | 화학Ⅰ 양적 관계, 물리학Ⅰ 역학, 생명과학Ⅰ 유전, 지구과학Ⅰ 별의 물리량, 사회·문화 도표 분석 | 공식과 계산 단계 | 숫자를 바꿔 자동 생성(수학과 같은 코드 구조) |
| 영어 | 빈칸 추론, 글의 순서, 문장 삽입, 어법 | 핵심 구문 해석, 연결사와 논리 흐름, 대명사가 가리키는 대상, 주제문 찾기 | 구문·어법은 문장 틀에 단어를 바꿔 생성. 지문은 LLM 초안을 사람이 검수 |
| 국어 | 문법, 독서 <보기> 적용 | 문법 개념(음운 변동, 문장 성분), 읽기 단계(문단 핵심 정리, 인과·조건 관계, 지문 개념과 <보기> 사례 대응) | 문법은 단어를 바꿔 생성. 지문은 LLM 초안을 사람이 검수 |

**권장 순서는 탐구 → 영어 → 국어입니다.** 탐구 계산형 문항은 지금 수학 코드에 문제와 생성 함수만 추가하면 됩니다. 영어와 국어는 지문을 새로 써야 해서 검수 인력이 필요하고, 국어 독서는 지문이 길고 한 지문에 문항이 여러 개 걸려 가장 손이 많이 갑니다.

**앱에 미리 넣어 둔 것**
- 과목 탭: 수학 외 과목은 `준비 중`으로 확장 계획을 보여 줍니다. `TARGETS`에 `subject: '영어'`인 문제를 넣으면 그 과목 탭에 바로 나타납니다.
- 5지선다 입력: 문제나 생성 결과에 `choices: [선택지 5개]`를 넣으면 숫자 키패드 대신 ①~⑤ 선택지가 나옵니다. 정답 `a`는 1~5.
- 지문 칸: `passage`(목표 문제) 또는 생성 결과의 `passage`에 넣으면 발문 아래에 지문이 나옵니다. `<span class="bogi">`로 <보기> 상자를 그립니다.
- 배점 표시: 목표 문제에 `pts: 3`처럼 넣습니다(기본 4).

**확장할 때 추가로 손볼 것**
- 국어 지문 세트: 한 지문에 문항 여러 개를 묶고, 목표 시간을 세트 단위(예: 10분)로 잡기
- 지문 속 단서 문장을 강조 표시해서 개념 카드와 연결하기
- 앱 이름: 국어·영어·탐구의 고난도 문항은 3점이라 '4점 사다리'가 수학에만 맞습니다. 확장할 때 이름을 정해야 합니다.
- 저작권: 수능·모의평가 기출 지문과 문항을 앱에 넣으려면 한국교육과정평가원의 이용 허락 조건을 확인해야 합니다. 지금처럼 자체 제작 문항을 기본으로 합니다.

## 그 밖에 할 일

- 수학 목표 문제 더 늘리기(수열의 합과 일반항, 함수의 그래프와 넓이, 지수함수 그래프 등). 학생 사용 결과를 보고 막히는 유형부터
- 학생이 직접 찍은 문제 사진을 개념으로 분해하는 기능(LLM 활용)
- 학습 기록을 계정에 저장해 기기 간 동기화, 교사용 반 단위 현황
