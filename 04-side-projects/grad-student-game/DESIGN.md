# 대학원생 키우기 · 게임 기획서 (v0.1 초안)

> **이름 변경 (2026-10-22)**: 이 문서의 '아인슈타인급'은 '살아있는 교과서', '노벨상급 학술상'·'노벨 메달'은 '황금 월계관'으로 바꿨습니다. 이유는 [랩실 도감](COLLECTION.md) 4절에 있습니다.

석박통합과정 대학원생 한 명의 6년을 한 달 단위로 계획해 졸업시키는 육성 시뮬레이션입니다. 플레이어는 매달 일정을 짜고, 대학원생은 그 일정대로 논문을 읽고, 측정하고, 제안서를 쓰다가 지치기도 합니다. 연구실에서 실제로 겪는 일(무향실 예약 충돌, 리뷰어 2, 마감 전날 제안서)을 게임 규칙과 이벤트로 옮깁니다.

> **방향 전환 (2026-10-22)**: 이 게임의 원래 참고작은 거지키우기(클리커·방치형)입니다. 그래서 [프로토타입](prototype/README.md)은 탭과 자동 생산 방식으로 만들었고, 직급 8단계와 연구실 소재만 이 문서와 [전직 시스템](CAREER.md)에서 가져왔습니다. 이 문서의 일정 배정형 규칙(활동 표, 논문 심사, 이벤트)은 보류합니다.

이 문서는 석사·박사 단계를 다룹니다. 포닥, 교수, 석학을 거쳐 아인슈타인급까지 올라가는 직급 단계는 [전직 시스템](CAREER.md)에 있습니다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 육성 시뮬레이션 (일정 배정형, 프린세스 메이커 방식) |
| 플랫폼 | 웹(PWA) + 안드로이드 앱(WebView). 일감 레이더와 같은 빌드 방식 |
| 한 판 길이 | 석박통합 6년 72턴, 30~40분. [전직 시스템](CAREER.md)을 넣으면 정년까지 약 200턴, 2~3시간 |
| 대상 | 대학원생, 대학원 진학을 고민하는 학부생, 대학원생을 둔 가족 |
| 재미 요소 | ① 체력·멘탈과 실적 사이에서 매달 일정을 고르는 고민 ② 논문 심사 결과를 기다리는 긴장 ③ "이거 우리 랩 얘기다" 하는 공감 이벤트 |

### 플레이어 시점

플레이어는 대학원생의 자취방에 사는 고양이 **야옹**입니다. 야옹이 매달 달력에 일정을 적어 두면 대학원생이 그대로 따릅니다. 다만 멘탈이 30 아래로 떨어지면 대학원생이 일정을 무시하고 쉬어 버릴 수 있습니다(4.3절).

지도교수는 플레이어가 아니라 NPC입니다. 교수가 NPC여야 "교수님 호출" 같은 돌발 이벤트로 플레이어의 계획을 흔들 수 있습니다.

## 2. 핵심 루프

```
[월초] 달력에 일정 3칸 배정 (상순·중순·하순)
   ↓
[진행] 칸마다 활동 실행 → 능력치·상태·연구 데이터 변화를 로그로 표시
   ↓
[이벤트] 조건이 맞는 이벤트 0~2개 발생 → 선택지 고르기
   ↓
[월말] 인건비 입금, 생활비 출금, 심사 중인 논문 결과 확인
   ↓
졸업 조건 또는 중도 하차 조건 확인 → 다음 달
```

- 1턴 = 1달, 1년 = 12턴. 한 달은 상순·중순·하순 3칸으로 나눕니다.
- 3월에 입학해 6년(72턴) 안에 졸업하는 것이 기본 목표입니다. 8년(96턴)이 지나면 강제 엔딩입니다.

## 3. 능력치와 상태

### 3.1 능력치 (0~100, 오르기만 함)

| 능력치 | 시작값 | 올리는 활동 | 쓰이는 곳 |
|---|---|---|---|
| 이론 | 15 | 논문 읽기, 수업, 시뮬레이션 | 논문 게재 확률, 졸업 심사 |
| 실험 | 10 | 측정, 제작 | 측정·제작 실패 확률 감소, 논문 게재 확률 |
| 코딩 | 10 | 신호처리 코딩, 시뮬레이션 | 데이터 생산량, AI 도구 효율 |
| 글쓰기 | 10 | 논문 쓰기, 제안서 | 원고 진척 속도, 논문 게재 확률 |
| 발표 | 10 | 랩미팅 준비, 학회 발표, 조교 | 학회 발표 평가, 졸업 심사 |

### 3.2 상태 (오르내림)

| 상태 | 범위·시작값 | 0 또는 바닥이 되면 |
|---|---|---|
| 체력 | 0~100, 80 | 0이 되면 입원 이벤트, 다음 달 3칸 모두 강제 휴식 |
| 멘탈 | 0~100, 70 | 30 미만이면 활동 효율 ×0.6, 일정 무시 확률 발생. 0이면 번아웃 이벤트(휴학 또는 자퇴 선택) |
| 교수 신뢰도 | 0~100, 50 | 60 미만이면 학회 출장과 예비심사 신청이 거절됨 |
| 통장 잔고 | 시작 300만 원 | 0 미만이면 아르바이트 강제 이벤트(한 달에 1칸 고정) |

### 3.3 연구 자원

| 자원 | 설명 |
|---|---|
| 연구 데이터 | 시뮬레이션·측정·코딩으로 쌓입니다. 논문 원고를 시작하려면 30이 필요하고, 원고를 시작할 때 30을 소모합니다. |
| 원고 진척 | 0~100%. 100%가 되면 투고할 수 있습니다. |
| 학위논문 진척 | 0~100%. 게재된 논문 1편당 +30%, 학위논문 쓰기 1칸당 +5%. |
| 코스웍 | 수업 24칸을 채우면 수료 조건 충족. 1~2년 차 학기 중에는 매달 1칸 이상 수업을 넣어야 합니다. |

## 4. 활동

### 4.1 활동 표 (1칸 기준)

| 활동 | 능력치 변화 | 체력 | 멘탈 | 그 밖의 효과 |
|---|---|---|---|---|
| 논문 읽기 | 이론 +3 | -2 | -2 | 다음 시뮬레이션 데이터 +1 |
| EM 시뮬레이션 | 이론 +2, 코딩 +1 | -3 | -3 | 연구 데이터 +4 |
| 측정 (VNA·무향실) | 실험 +3 | -6 | -3 | 연구 데이터 +6. 무향실 예약 성공률 70%, 실패하면 데이터 없이 체력만 소모 |
| 제작 (PCB·납땜·지그) | 실험 +3 | -5 | -2 | 다음 측정 데이터 +3. 실패 확률 = 30% - 실험/5 % |
| 신호처리 코딩 | 코딩 +3 | -3 | -2 | 연구 데이터 +3 |
| 논문 쓰기 | 글쓰기 +3 | -3 | -5 | 원고 진척 +(5 + 글쓰기/5)% |
| 제안서 지원 | 글쓰기 +1 | -5 | -6 | 교수 신뢰도 +5, 다음 달 인건비 +30만 원 |
| 랩미팅 준비 | 발표 +3 | -2 | -3 | 교수 신뢰도 +2 |
| 수업 | 이론 +2 | -2 | -2 | 코스웍 +1칸 |
| 조교 | 발표 +1 | -4 | -3 | 통장 +40만 원 |
| 학위논문 쓰기 | 글쓰기 +2 | -3 | -4 | 학위논문 진척 +5% (4년 차부터) |
| 휴식 | - | +15 | +10 | 교수 신뢰도 -1 |
| 취미·여행 | - | +5 | +20 | 통장 -30만 원 |

### 4.2 활동 효율 공식

```
실제 효과 = 기본값 × 멘탈 계수 × 연속 보너스 × 교수 성향 배율
  멘탈 계수: 멘탈 30 이상 1.0, 30 미만 0.6
  연속 보너스: 같은 활동을 3칸 연속 넣으면 세 번째 칸 효과 ×1.2 (몰입)
  교수 성향 배율: 5절 표 참조
```

### 4.3 일정 무시

멘탈이 30 미만이면 칸마다 (30 - 멘탈) × 2 % 확률로 대학원생이 배정된 활동 대신 휴식을 합니다. 로그에 "오늘은 도저히 못 하겠다…"가 뜹니다. 플레이어는 이 확률을 보고 휴식을 미리 넣을지 고릅니다.

### 4.4 해금 활동

| 활동 | 해금 조건 | 효과 |
|---|---|---|
| AI 코딩 에이전트 활용 | 코딩 40 이상, 2년 차 이후 | 같은 칸에서 시뮬레이션 또는 코딩을 2번 실행. 10% 확률로 "에이전트가 엉뚱한 파일을 고침" 이벤트(멘탈 -5) |
| 후배 지도 | 후배 입학 이벤트 이후 | 발표 +2, 교수 신뢰도 +2, 연구 데이터 +2 |

## 5. 지도교수 성향

게임을 시작할 때 아래 네 성향 중 하나가 무작위로 정해지고, 첫 랩미팅 이벤트에서 공개됩니다. 성향마다 활동 배율과 이벤트 빈도가 달라서 판마다 짜야 할 전략이 바뀝니다.

| 성향 | 활동 배율 | 이벤트 빈도 변화 |
|---|---|---|
| 방목형 | 모든 활동 ×1.0, 교수 신뢰도 변화 ×0.5 | 교수님 호출 ×0.3, 대신 졸업 심사 기준 +10 |
| 마이크로매니저 | 랩미팅 준비 ×1.5 | 교수님 호출 ×2, "어디야?" 메시지 이벤트 추가 |
| 과제 부자 | 제안서 지원 인건비 ×2 | 제안서 마감 이벤트 ×3 |
| 논문 집착형 | 논문 쓰기 ×1.3 | 투고 전 원고 반려 이벤트(원고 진척 -20%) 추가 |

## 6. 논문 시스템

### 6.1 진행 순서

```
연구 데이터 30 소모 → 원고 시작 → 논문 쓰기로 진척 100% → 투고 (학회 또는 저널 선택)
  → 심사 대기 → 결과: 게재 승인 / 소폭 수정 / 대폭 수정 / 게재 불가
```

| 구분 | 투고 조건 | 심사 기간 | 기본 게재 확률 | 게재 시 보상 |
|---|---|---|---|---|
| 국내 학회 | 원고 50% | 1턴 | 70% | 발표 기회, 멘탈 +10 |
| 국제 학회 | 원고 70% | 2턴 | 50% | 발표 기회, 출장(통장 -100만 원, 멘탈 +20) |
| SCI 저널 | 원고 100% | 3~6턴 무작위 | 6.2절 공식 | 졸업 실적 1편, 학위논문 진척 +30% |

### 6.2 저널 심사 결과 확률

```
점수 = 20 + (이론 + 실험 + 글쓰기) / 6 + (투고 시 남은 연구 데이터 / 2)   (최대 85)
게재 승인: 점수 × 0.2
소폭 수정: 점수 × 0.5
대폭 수정: 점수 × 0.3
게재 불가: 100 - 점수
```

- 소폭 수정: 원고 진척이 80%로 내려가고, 다시 100%로 채워 제출하면 게재.
- 대폭 수정: 원고 진척 50%로 내려가고 연구 데이터 15를 추가로 써야 재제출 가능. 재심사 결과는 같은 공식으로 다시 굴립니다.
- 게재 불가: 원고 진척 70%로 내려가고, 다른 저널에 다시 투고할 수 있습니다. 멘탈 -15.

이벤트는 매달 말에 조건을 만족하는 후보 중 가중치 추첨으로 0~2개가 나옵니다. MVP에는 아래 15개를 넣습니다.

| 이벤트 | 발생 조건 | 선택지와 결과 |
|---|---|---|
| 교수님 호출: 내일까지 제안서 | 무작위, 과제 부자 ×3 | ① 밤새 쓴다: 다음 달 첫 칸이 제안서로 고정, 체력 -15, 신뢰도 +8 ② 다른 마감이 있다고 말한다: 신뢰도 -10 |
| 무향실 예약 충돌 | 측정 활동이 있는 달 | ① 새벽 시간 예약: 체력 -10, 측정 성공 ② 다음 달로 미룬다 |
| 리뷰어 2 | 저널 대폭 수정 결과 | ① 반박서 정성껏 쓰기: 글쓰기 +3, 멘탈 -10 ② 요구대로 실험 추가: 연구 데이터 -10, 재심 점수 +10 |
| VNA 교정 키트 실종 | 측정 3회 이상 이후 무작위 | 다음 측정 1칸 실패, 랩 단톡방 이벤트로 이어짐 |
| 학회 출장 | 국제 학회 게재 | 발표 판정(발표 능력치), 성공 시 멘탈 +20, 신뢰도 +5 |
| 논문공모전 | 매년 9월, 저널 게재 1편 이상 | 참가하면 발표 판정, 수상 시 통장 +100만 원, 수상 실적 +1 |
| BK21 장학금 | 매년 3월, 실적 2건 이상 | 통장 +200만 원 |
| 후배 입학 | 2년 차 3월 | 후배 지도 활동 해금 |
| 인건비 지연 | 무작위, 과제 부자 ×0.5 | 이번 달 인건비 0원, 다음 달 2배 |
| 명절 귀향 | 1월·9월 | ① 집에 간다: 멘탈 +15, 1칸 소모 ② 랩에 남는다: 멘탈 -10 |
| 동기 취업 소식 | 3년 차 이후 무작위 | 멘탈 -10. "나도 그만둘까" 선택지 → 석사 졸업 엔딩 분기 |
| 연구실 회식 | 분기마다 | 멘탈 +5, 체력 -5, 신뢰도 +2 |
| 번아웃 | 멘탈 0 | ① 휴학 6턴: 체력·멘탈 회복, 졸업 기간 6턴 연장 ② 자퇴 → 중도 하차 엔딩 |
| 입원 | 체력 0 | 다음 달 강제 휴식, 통장 -50만 원 |
| 야옹의 방해 | 무작위 1% | 노트북 위에 앉아 원고 진척 -3%, 멘탈 +10 |

## 8. 졸업과 엔딩

### 8.1 박사 졸업 조건

1. 코스웍 24칸 완료
2. SCI 저널 제1저자 2편
3. 학회 발표 2회
4. 학위논문 진척 100%
5. 교수 신뢰도 60 이상에서 예비심사 신청 → 통과 후 3턴 뒤 본심사 통과

예비심사·본심사 판정은 `(이론 + 발표) / 2 ≥ 60 (방목형은 70)`입니다. 떨어지면 3턴 뒤에 다시 신청할 수 있습니다.

### 8.2 엔딩 목록

[전직 시스템](CAREER.md)을 넣으면 졸업은 엔딩이 아니라 3단계 포닥으로 가는 전직이 됩니다. 아래 진로 엔딩은 졸업 시점에 학계를 떠나는 선택지로 남고, 교수 임용과 해외 포닥은 엔딩 목록에서 빼고 포닥 단계로 옮겼습니다.

| 엔딩 | 조건 |
|---|---|
| 국책연구소 연구원 | 졸업 + 저널 3편 이상 |
| 대기업 연구원 | 졸업 + 실험 70 이상 |
| AI 스타트업 창업 | 졸업 + 코딩 80 이상 + AI 에이전트 활용 20회 이상 |
| 조기 졸업 | 5년(60턴) 안에 졸업 (위 진로 엔딩과 함께 표시) |
| 석사 졸업 후 취업 | "동기 취업 소식"에서 그만두기 선택, 저널 1편 이상 |
| 자퇴 | 번아웃 이벤트에서 자퇴 선택 |
| 연구실 화석 | 8년(96턴) 동안 졸업 못 함 |
| 히든: 교수님과 공동 창업 | 졸업 + 교수 신뢰도 100 + 과제 부자 성향 |

엔딩 화면에는 6년 동안의 실적을 CV 형식(논문 목록, 학회 발표, 수상)으로 보여 주고, 이미지로 저장해 공유할 수 있게 합니다.

## 9. 화면 구성

| 화면 | 들어가는 내용 |
|---|---|
| 메인 | 상단에 연차·월, 가운데 대학원생 그림(상태별 4종: 멀쩡, 피곤, 번아웃 직전, 졸업), 하단에 체력·멘탈·신뢰도·잔고 막대 |
| 일정 배정 | 달력 3칸에 활동 카드를 끌어다 놓기. 카드에 예상 체력·멘탈 변화를 숫자로 표시 |
| 진행 로그 | 칸마다 한 줄씩 결과 표시 ("무향실 예약 실패. 오늘도 복도에서 기다렸다.") |
| 이벤트 창 | 상황 설명 + 선택지 2개, 선택지별 예상 효과는 숨김 |
| 연구 현황 | 원고 진척, 심사 중 논문과 남은 턴, 졸업 조건 체크리스트 |
| 엔딩 | 엔딩 일러스트, CV, 공유 버튼 |

MVP 그래픽은 이모지와 단색 일러스트로 만들고, 반응을 보고 도트 그래픽으로 바꿀지 정합니다.

## 10. 기술 구성

- **화면**: HTML + JavaScript 한 페이지. 프레임워크 없이 시작합니다.
- **게임 데이터**: 활동·이벤트·엔딩을 JSON 파일로 분리해, 코드를 고치지 않고 수치와 문구를 바꿀 수 있게 합니다.
- **저장**: localStorage에 매 턴 자동 저장. 저장 슬롯 3개.
- **난수**: 시드 고정 난수를 써서 같은 시드면 같은 결과가 나오게 합니다. 버그 재현과 밸런스 테스트에 씁니다.
- **배포**: Vercel(PWA) + 안드로이드 WebView 앱. 일감 레이더처럼 Gradle 없이 빌드합니다.

### 밸런스 검증

게임 엔진을 화면과 분리해 Node.js에서 자동 플레이를 돌립니다. 전략별로 1,000판씩 돌려 졸업률과 평균 졸업 기간을 잽니다.

| 전략 | 목표 졸업률 | 목표 평균 졸업 기간 |
|---|---|---|
| 무작위 배정 | 20% 미만 | - |
| 휴식 없이 연구만 | 30% 미만 (번아웃으로 탈락) | - |
| 체력·멘탈 50 이상 유지 + 연구 위주 | 60~80% | 6년 ± 6개월 |

목표에서 벗어나면 4.1절 활동 표와 6.2절 게재 확률 수치를 조정합니다.

## 12. 정해야 할 것

- **풍자 수위**: 교수 성향과 이벤트 문구가 실제 연구실을 떠올리게 합니다. 공개 배포한다면 실제 학회명(APMC 등)과 장학금명(BK21)을 그대로 쓸지, 가상 이름으로 바꿀지 정해야 합니다.
- **전공 범위**: 지금 활동은 RF·안테나 연구실 기준입니다. 다른 전공(바이오, 인문) 플레이어를 받으려면 시작할 때 전공을 고르고 활동 이름만 바꾸는 방식을 검토합니다.
- **게임 저장소**: 개발을 시작하면 별도 저장소를 만들고, 이 기획서를 그 저장소로 옮긴 뒤 이 폴더에는 링크만 남깁니다.
