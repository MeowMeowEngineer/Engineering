# 대학원생 키우기 · 클리커·방치형 게임 점검 목록과 QA 결과

이 장르를 만들 때 놓치기 쉬운 항목을 영역별로 정리하고, [프로토타입](prototype/README.md)이 각 항목을 어떻게 처리하는지 적었습니다. 2절은 자동 QA 결과, 3절은 이번 QA에서 찾아 고친 버그, 4절은 아직 남은 위험입니다.

상태 표기는 이렇습니다. **통과**는 구현했고 확인까지 했다는 뜻입니다. **부분**은 대응은 했지만 한계가 있다는 뜻입니다. **미대응**은 출시 전에 해야 한다는 뜻입니다.

## 1. 장르 점검 목록

### 1.2 숫자와 시간

|---|---|---|---|

### 1.4 부정 플레이

| 점검 항목 | 왜 중요한가 | 프로토타입 | 상태 |

## 3. 이번 QA에서 찾아 고친 버그

| 버그 | 원인 | 수정 |
|---|---|---|
| 페이지 파일을 직접 열면 탭이 안 됨 | 모달의 `display: grid`가 `hidden` 속성을 덮어써 닫힌 모달이 화면을 가림 | `[hidden] { display: none !important; }` 추가 |
| 야옹이 캐릭터만큼 커져 얼굴을 가림 | 캐릭터 SVG 크기 규칙이 고양이 SVG에도 적용됨 | 고양이 크기 규칙의 우선순위를 높임 |
| 버프 남은 시간이 '29분 60초'로 표시됨 | 초를 올림한 뒤 60으로 나머지를 구함 | 전체 초를 먼저 올림하고 분·초로 나눔 |
| 레벨 보너스를 넣자 방치형이 8시간 만에 엔딩 | 레벨·직급·논문 배율이 곱해져 성장 폭주 | 시뮬레이터 탐색으로 논문 비용·전직 기준 재조정 |

## 4. 남은 위험과 정할 것

1. **실존 인물·상표 이름**: 공개 배포 전에 정해야 합니다. 바꾼다면 '아인슈타인급'은 '전설의 석학'으로, '노벨 메달'은 '황금 메달'로, 캐릭터는 흰 머리 대신 다른 외형으로 바꾸는 방법이 있습니다.
2. **재입학 이후 콘텐츠**: 첫 판이 하루면 끝납니다. 메달로 사는 영구 강화 목록이 필요합니다([BM](BM.md) 5절).
3. **서버 저장**: 결제 재화, 출석, 구독 기간은 정식 출시 때 서버로 옮겨야 시계 조작과 기기 변경 문제를 막을 수 있습니다.
4. **실기기 테스트**: 자동 QA는 데스크톱 크로미움에서만 돌았습니다. 안드로이드 WebView에서의 탭 반응, 배터리 소모, 백그라운드 복귀는 실제 폰으로 확인해야 합니다.
