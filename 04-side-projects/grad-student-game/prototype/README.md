# 대학원생 키우기 · 클리커 프로토타입

거지키우기처럼 탭해서 재화를 모으고, 자동 생산을 늘리고, 단계가 오를수록 캐릭터가 바뀌는 클리커·방치형 게임입니다. 직급 8단계는 [전직 시스템](../CAREER.md)의 이름과 칭호를 그대로 씁니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 빌드는 필요 없습니다. `engine.js`가 같은 폴더에 있어야 합니다.

## 규칙

| 요소 | 내용 |
|---|---|
| 탭 | 대학원생을 탭하면 연구 데이터를 얻습니다. 탭 강화 1레벨마다 2배가 됩니다. 포닥부터는 탭 1번에 초당 생산의 2%가 더해집니다. |
| 동료·장비 | 커피 머신, 학부연구생부터 석학 연구원까지 11종입니다. 1대 살 때마다 가격이 1.15배 오릅니다. 10·25·50·100대를 보유하면 그 생산원의 효율이 2배가 됩니다. 직급이 오를 때마다 새 생산원이 열립니다. |
| 논문 | 데이터를 써서 논문을 냅니다. 논문 1편마다 자동 생산 +3%입니다. 비용은 1편마다 1.45배 오르고, 첫 5편은 할인합니다. |
| 전직 | 누적 논문 편수로 전직합니다. 박사과정 3편, 포닥 7편, 조교수 12편, 부교수 18편, 정교수 25편, 석학 32편이 필요합니다. 아인슈타인급은 38편과 세기의 연구(데이터 30억)가 필요합니다. 전직할 때마다 자동 생산 ×1.5, 탭 ×1.5가 됩니다. |
| 스킬 | 밤샘은 30초 동안 탭 10배이고, 5분마다 쓸 수 있습니다. 마감 버프는 박사과정부터 쓸 수 있고, 30초 동안 자동 생산 3배이며 10분마다 쓸 수 있습니다. |
| 지나가는 교수님 | 1~2분마다 화면을 가로지릅니다. 잡으면 다음 중 하나를 받습니다: 연구비(데이터 1분 치), 영감(20초 동안 탭 7배), 과제 선정(20초 동안 자동 생산 5배). |
| 방치 보상 | 앱을 닫아 둔 시간만큼 자동 생산의 50%를 받습니다. 최대 8시간입니다. |
| 재입학 | 아인슈타인급이 되면 노벨 메달 1개를 들고 처음부터 다시 시작할 수 있습니다. 메달 1개마다 생산과 탭이 영구히 50% 늘어납니다. |

## 밸런스

`node sim.js`를 실행하면 두 가지 플레이어 유형으로 끝까지 자동 플레이하고, 직급별 도달 시각을 출력합니다. 조정값은 `engine.js`의 `CFG` 한 곳에 모여 있습니다. 시뮬레이터 결과(재입학 전 첫 판 기준, 분)는 아래와 같습니다.

| 플레이어 | 박사과정 | 포닥 | 조교수 | 부교수 | 정교수 | 석학 | 아인슈타인급 |
|---|---|---|---|---|---|---|---|
| 적극적 (초당 5탭, 스킬 사용, 교수님을 잡음) | 3 | 9 | 13 | 19 | 26 | 35 | 51 |
| 가벼움 (초당 1탭) | 15 | 26 | 34 | 42 | 55 | 76 | 117 |
