# 대학원생 키우기 · 클리커 프로토타입

거지키우기처럼 탭해서 재화를 모으고, 자동 생산을 늘리고, 단계가 오를수록 캐릭터가 바뀌는 클리커·방치형 게임입니다. 앱을 꺼 둬도 경험치와 데이터가 쌓입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 빌드는 필요 없고, `engine.js`가 같은 폴더에 있어야 합니다.

| 파일 | 내용 |
|---|---|
| `engine.js` | 게임 규칙. 화면과 분리돼 Node에서도 돌아감 |
| `index.html` | 화면 |
| `sim.js` | 밸런스 시뮬레이터 (`node sim.js`) |
| `qa.js` | 엔진 단위 검사 12개 + 브라우저 QA 28개 (`node qa.js`, Playwright 필요) |

## 규칙

| 요소 | 내용 |
|---|---|
| 탭 | 대학원생을 탭하면 연구 데이터를 얻습니다. 탭 강화 1레벨마다 2배. 포닥부터는 탭 1번에 초당 생산의 2%가 더해집니다. 1초에 15번까지만 인정합니다. |
| 연구실 장면 | 캐릭터가 논문 쓰기·실험·데이터 분석·아이디어 구상을 번갈아 하고, 플레이어 행동에 따라 장면이 바뀝니다. |
| 동료·장비 | 커피 머신, 공용 실험 장비, GPU 서버부터 석학 연구원까지 12종. 1대 살 때마다 가격 1.15배, 10·25·50·100대 보유 시 효율 2배. 직급이 오르면 새로 열립니다. 시간강사는 '출강 학교'를 엽니다. |
| 경험치·레벨 | 1초마다 경험치 1, 탭 1번에 0.5. 앱을 꺼 둔 동안에도 오릅니다. 레벨마다 생산·탭 +3%, 10레벨마다 커피 쿠폰 5개. |
| 논문 | 데이터로 논문을 냅니다. 1편마다 자동 생산 +3%. 비용은 1편마다 1.45배이고 첫 7편은 할인합니다. |
| 자동화 | 박사과정부터 '자동 투고'(후배가 데이터가 모이면 논문을 냄), 포닥부터 '자동 고용'(데이터 절반 안에서 효율 좋은 동료·장비를 삼). 방치 중에도 작동합니다. |
| 연차 | 석사과정 1~2년차, 박사과정 1~4년차. 그 과정에서 쓴 논문 수로 오르고 1년마다 자동 생산 +10% |
| 과제 | 산학과제(중소·중견·대기업)와 국가과제(중소·중견·대기업 주관 각 2개). 정해진 시간 뒤 보상, 진행 중 생산 보너스, 방치 중에도 진행 |
| 전직 9단계 | 석사과정 → 박사과정(논문 3편) → 포닥(7) → 시간강사(11) → 조교수(16) → 부교수(22) → 정교수(29) → 석학(37) → 살아있는 교과서(45편 + 세기의 연구). 전직마다 자동 생산·탭 ×1.5. |
| 스킬 | 밤샘(30초 탭 10배, 5분마다), 마감 버프(박사과정부터, 30초 생산 3배, 10분마다) |
| 지나가는 교수님 | 1~2분마다 지나갑니다. 잡으면 연구비, 영감(탭 7배), 과제 선정(생산 5배) 중 하나 |
| 방치 보상 | 꺼 둔 시간만큼 자동 생산의 50%, 최대 8시간(구독 시 100%, 12시간). 광고를 보면 2배 |
| 재입학·월계관 | 살아있는 교과서가 된 뒤 황금 월계관(기본 3개+)을 받고 처음부터. 가진 월계관 1개당 생산·탭 +20%, 또는 영구 강화 9종에 씀. 도감·쿠폰·야옹·구매 내역·평생 기록은 유지 |
| 랩실 도감 | 교수님 어록 16, 학회 굿즈 12, 연구 주제 10×★3, 직급 기념사진 9, 야옹 사진 8. 플레이로만 얻고 재입학해도 남습니다. 항목마다 영구 보너스, 세트 완성 보너스가 있고 확률을 공개합니다. 자세한 내용은 [도감](../COLLECTION.md) |
| 랭킹·클라우드 저장 | claude.ai에서 공유된 게임을 열면 켜짐. 닉네임으로 참가하고 종합 점수·최단 엔딩·도감·과제 실적으로 정렬 |
| 상점 (BM 시뮬레이션) | 출석, 보상형 광고, 커피 쿠폰, 가상 결제 상품. 실제 결제·광고는 없습니다. 자세한 내용은 [BM](../BM.md) |

## 밸런스

조정값은 `engine.js`의 `CFG` 한 곳에 있습니다. `node sim.js` 결과(첫 판, 무과금)는 아래와 같습니다.

| 플레이 방식 | 박사과정 | 시간강사 | 조교수 | 정교수 | 석학 | 살아있는 교과서 |
|---|---|---|---|---|---|---|
| 적극 (초당 5탭, 스킬, 교수님) | 2분 | 12분 | 16분 | 28분 | 40분 | 1.1시간 |
| 가벼움 (초당 1탭) | 14분 | 30분 | 38분 | 59분 | 1.4시간 | 2.2시간 |
| 4시간마다 2분 접속 | 4.0시간 | 8.1시간 | 8.1시간 | 8.1시간 | 12.1시간 | 12.1시간 |
| 12시간마다 5분 접속 | 8.1시간 | 8.1시간 | 16.2시간 | 16.2시간 | 16.2시간 | 1.0일 |

재입학을 반복하면 월계관 강화와 도감 보너스로 한 판이 짧아집니다(4시간마다 접속 기준 1판 12.1시간 → 4판부터 8.1시간).

연차·과제·월계관 강화·랭킹은 [진행 시스템](../PROGRESSION.md), 점검 목록과 QA 결과는 [QA](../QA.md)에 있습니다.
