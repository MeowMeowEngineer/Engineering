# Play 스토어 등록 정보 (한국어)

Play Console → 성장 → 스토어 등록정보 → 기본 스토어 등록정보에 그대로 붙여 넣는다. 글자 수 제한은 앱 이름 30자, 간단한 설명 80자, 자세한 설명 4,000자다.

## 앱 이름 (8자)

```
대학원생 키우기
```

## 간단한 설명 (47자)

```
석사 1년차 막내가 살아있는 교과서가 되기까지. 탭하고 논문 쓰고 심사를 통과하세요.
```

## 자세한 설명

```
석사 1년차 연구실 막내로 시작해 박사, 시간강사, 교수를 거쳐 '살아있는 교과서'가 되는 대학원 방치형 게임이에요.

■ 탭해서 연구 데이터 모으기
대학원생을 탭하면 연구 데이터가 쌓여요. 데이터가 모이면 논문을 쓰고, 논문 수가 차면 다음 단계 심사를 신청할 수 있어요.

■ 동료와 장비 들이기
커피 머신, 학부연구생, 후배 대학원생, 실험 장비, GPU 서버를 들이면 자리를 비운 동안에도 데이터가 쌓여요. 앱을 닫아 두어도 다시 열면 그동안 모인 데이터를 받아요.

■ 실시간 심사
박사과정부터는 승진마다 실제 시간이 걸리는 심사를 거쳐요. 심사 중에 탭하면 남은 시간이 줄어들어요. 바쁜 날은 켜 두고, 한가한 날은 열심히 탭해서 심사를 앞당겨 보세요.

■ 방문객과 과제
지도교수님, 학과장님, 총장님이 연구실에 들르면 탭해서 보상을 받으세요. 단계가 오르면 산학과제와 국가과제도 맡을 수 있어요.

■ 도감 모으기
은사님 어록, 학회 굿즈, 상장(학과 공모전 우수상부터 장관상, Best Paper까지), 승진 기념사진을 모아 보세요. 세트를 채우면 영구 보너스가 붙어요.

■ 커피와 에너지 드링크
마감이 다가오면 커피로 버티고, 급할 때는 에너지 드링크로 생산을 끌어올리세요.

■ 이런 분께 추천해요
· 대학원에 다니고 있거나 다녔던 분
· 출퇴근길에 잠깐씩 켜 두는 방치형 게임을 찾는 분
· 숫자가 커지는 걸 보는 게 즐거운 분

인터넷 없이도 할 수 있고, 광고와 결제가 없어요. 진행 상황은 기기 안에만 저장돼요.

※ 게임에 나오는 학교, 인물, 기관은 모두 지어낸 것이에요.
```

## 분류와 태그

- 앱 또는 게임: 게임
- 카테고리: 시뮬레이션 (대안: 캐주얼)
- 태그(최대 5개): 방치형, 시뮬레이션, 클리커, 캐주얼, 싱글플레이어

## 그래픽 파일

| 항목 | 파일 | 규격 |
|---|---|---|
| 앱 아이콘 | `store/icon-512.png` | 512×512 PNG, 1MB 이하 |
| 그래픽 이미지 | `store/feature-graphic-1024x500.png` | 1024×500 PNG |
| 휴대전화 스크린샷 | `store/screenshots/1-start.png` ~ `5-promotion.png` | 1080×1920 PNG, 2~8장 |

스크린샷은 `npm run build && NODE_PATH=$(npm root -g) node qa-release.js`를 실행하면 다시 만들어진다. 순서는 시작 화면 → 중반 연구실 → 심사 중 → 도감 → 전직 화면이다.

## 연락처

- 이메일: 필수. 사용자 문의를 받을 주소를 Play Console에 직접 입력한다.
- 웹사이트: 선택
- 개인정보처리방침 URL: 필수. `store/privacy-policy.html`을 공개 주소에 올리고 그 주소를 넣는다(RELEASE.md 4절).
