# 랩실 운영하기 · 타이쿤 프로토타입

> 교수가 되어 랩실을 운영하라

[클리커 버전](../prototype/README.md)과 비교하려고 따로 만든 두 번째 버전입니다. 클리커 버전은 대학원생 한 명을 탭해서 키우고, 이 버전은 조교수가 되어 연구실 전체를 짓고 운영합니다. 화면은 비스듬히 내려다보는 아이소메트릭 시점입니다. 감옥 운영 같은 방치형 타이쿤의 생산 흐름에, 화이트아웃 서바이벌·클래시 오브 클랜식 성장 장치(메인 건물이 다른 건물의 한계를 정하는 구조, 공사 타이머, 학과 연구, 연구원 카드, 일일 미션, 연맹)를 붙였습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. `engine.js`가 같은 폴더에 있어야 합니다.

| 파일 | 내용 |
|---|---|
| `engine.js` | 게임 규칙 (화면과 분리, Node에서도 돌아감) |
| `index.html` | 아이소메트릭 연구실 화면과 운영 패널 |
| `sim.js` | 밸런스 시뮬레이터 (`node sim.js`) |
| `qa.js` | 브라우저 QA 30개 (`node qa.js`, Playwright 필요) |

## 핵심 구조: 세 단계 생산 흐름

```
연구 공간(실험실·서버실·클린룸·대형 장비실·국제 공동연구센터) ─데이터→ 회의실(논문화) ─논문→ 교수실(투고·과제) ─→ 연구비 + 명성
```

- 초당 처리량은 세 단계 중 가장 느린 곳이 정합니다. 화면 아래 흐름 막대와 지도의 빨간 '병목' 표시가 지금 키워야 할 곳을 알려 줍니다.
- 연구 공간은 학생이 앉아야 데이터를 만듭니다. 좌석은 방 레벨에 따라 2~10석입니다.
- 회의실과 교수실은 처리 용량이고, 승진할 때마다 1.6배가 됩니다.
- 학생은 데이터를 들고 회의실로, 논문을 들고 교수실로 걸어갑니다. 교수실에서는 연구비 동전이 튀어 오릅니다.

## 대학 본관 (메인 건물)

지도 뒤쪽의 대학 본관은 클래시 오브 클랜의 마을회관과 같은 역할을 합니다. 작은 나라 지방 사립대에서 시작해 세계적 명문대로 승격시키는 것이 한 판의 최종 목표입니다.

| 단계 | 대학 | 승격 조건 | 승격 비용·시간 | 교수실 최대 레벨 | 새로 생기는 부지 |
|---|---|---|---|---|---|
| 1 | 지방 사립대 | 시작 | — | 30 | 교수실·회의실·휴게실·실험실 |
| 2 | 지방 거점 국립대 | 부교수 | 1,000 · 1분 | 60 | 서버실·자료실 |
| 3 | 수도권 종합대 | 정교수 | 200만 · 3분 | 110 | 클린룸 |
| 4 | 서울 명문 사립대 | 석학 | 30억 · 8분 | 170 | 대형 장비실·국제 공동연구센터 |
| 5 | 세계적 명문대 | 석학 | 3천억 · 15분 | 250 | — |

- 본관이 교수실의 최대 레벨을 정하고, 교수실이 다른 방의 최대 레벨(교수실 + 10)을 정합니다.
- 대학 단계가 하나 오를 때마다 명성 +15%입니다.
- 승격 공사는 방 공사와 같은 공사 대기열을 씁니다.
- 살아있는 교과서로 승진하고 대학이 세계적 명문대가 되면 엔딩입니다. 둘 중 늦게 끝나는 쪽에서 엔딩이 뜹니다.

## 방 (3×3 부지)

| 방 | 역할 | 열리는 대학 단계 | 공사비 · 공사 시간 |
|---|---|---|---|
| 교수실 | 투고 용량 | 1 | 기본 |
| 회의실 | 논문화 용량 | 1 | 기본 |
| 휴게실 | 학생 정원(분위기) | 1 | 기본 |
| 실험실 | 데이터 생산 (학생 1명당 기본 1) | 1 | 기본 |
| 서버실 | 데이터 생산 (기본 10) | 2 | 1,500 · 1분 30초 |
| 자료실 | 연구비 배율 (레벨당 +5%) | 2 | 3,000 · 2분 |
| 클린룸 | 데이터 생산 (기본 110) | 3 | 20만 · 5분 |
| 대형 장비실 | 데이터 생산 (기본 1,300) | 4 | 3천만 · 10분 |
| 국제 공동연구센터 | 데이터 생산 (기본 16,000) | 4 | 6억 · 15분 |

레벨 10·25·50·100에 닿는 업그레이드는 대공사입니다. 1분·3분·10분·30분이 걸리고, 끝나면 생산 공간의 효율이 2배가 됩니다.

## 가구·장비

방마다 가구와 장비가 5종 있고, 하나씩 따로 10레벨까지 올립니다. 레벨 1·4·7·10에서 모습이 바뀌고, 지도에도 그 모습이 그려집니다.

| 방 | 가구·장비 (모습 변화 예) |
|---|---|
| 교수실 | 책상(합판 → 마호가니 대가의 책상), 의자(접이식 → 가죽 중역 의자), 컴퓨터(중고 데스크톱 → 트리플 모니터 워크스테이션), 책장, 상패 진열장 |
| 회의실 | 회의 테이블, 의자, 화이트보드(이젤 보드 → 전자 칠판), 빔프로젝터(중고 빔 → 화상회의 시스템), 커피 포트 |
| 휴게실 | 소파, 커피 머신, 간식 냉장고, 낮잠 침대(간이 침대 → 호텔식 침대), 게임기 |
| 실험실 | 실험대, 실험 의자, 피펫·플라스크(유리 플라스크 → 자동 분주기), 현미경(교육용 → 공초점 현미경), 흄후드 |
| 서버실 | 서버 랙, 책상과 의자, GPU(게이밍 GPU → GPU 클러스터), 냉각 장치(선풍기 → 수랭 시스템), 무정전 전원 |
| 자료실 | 서가, 열람 책상, 열람 의자, 논문 DB 구독, 스캐너 |
| 클린룸 | 방진복 보관함, 클린 벤치, 증착 장비, 공조 설비, 측정 장비 |
| 대형 장비실 | 운영 인력석, 제어 컴퓨터, 핵심 장비, 예약 시스템, 안전 설비 |
| 국제 공동연구센터 | 화상 회의실, 공동 서버, 통역 지원, 방문 연구원 숙소, 공유 책상 |

- 효과는 그 방 산출 증가, 좌석 증가(실험대·랙 등), 휴게 정원 증가, 연구비·명성 증가 중 하나입니다.
- 첫 두 종은 방을 지으면 바로, 나머지는 방 레벨 5·10·25에서 열립니다.

## 운영 요소

| 요소 | 내용 |
|---|---|
| 학생 모집 | 연구비로 뽑습니다. 빈자리가 있어야 뽑을 수 있고, 학부연구생·석사·박사·포닥 중 무작위로 들어옵니다. |
| 연구실 분위기 | 학생이 휴게실 정원을 넘으면 1명당 7%씩 떨어집니다(최저 35%). 분위기만큼 처리량이 줄어듭니다. |
| 독려 | 방을 누르고 '독려하기'를 누르면 15초 동안 그 방이 2배가 됩니다. 방마다 45초 쿨다운입니다. |
| 학과 연구 | 7갈래(실험 효율, 논문 작성법, 행정, 복지, 장학금, 공사 기술, 홍보). 연구비와 시간이 들고 한 번에 하나만 진행합니다. |
| 스타 연구원 | 모집권으로 뽑는 카드 12명(일반·희귀·영웅·전설). 방에 배치하면 상시 1.5~5배, 스킬을 쓰면 20~30초 동안 3~8배. 같은 연구원이 또 나오면 별이 오릅니다. 영웅 이상 없이 10번 뽑으면 다음은 영웅 이상 확정. 등급 확률을 화면에 공개합니다. |
| 모집권 | 일일 미션, 승진, 과제 선정 이벤트, 컨소시엄 주간 목표에서 무료로만 얻습니다. 결제 상품은 없습니다. |
| 일일 미션 | 업그레이드 20번, 학생 2명 모집, 독려 5번, 이벤트 2개, 학과 연구 1번. 하나마다 모집권 1장과 연구비 5분 치, 모두 끝내면 모집권 2장 더. |
| 공사 대기열 | 시간이 걸리는 공사(새 방, 대공사, 대학 승격)는 1칸, 정교수부터 2칸 |
| 돌발 이벤트 | 1.5~2.5분마다 지도 위에 뜹니다. 20초 안에 눌러서 처리합니다. |
| 승진 | 명성이 쌓이면 조교수 → 부교수(1천) → 정교수(30만) → 석학(6천만) → 살아있는 교과서(120억). 승진마다 데이터 1당 연구비 ×2.5, 회의실·교수실 용량 ×1.6, 모집권 2장 |
| 정년 퇴임 | 엔딩 뒤 황금 월계관 3개 이상을 받고 새 지방 사립대에서 다시 시작합니다. 월계관 1개당 연구비 +25%. 스타 연구원·모집권·컨소시엄은 남습니다. |
| 방치 보상 | 앱을 꺼 둔 시간 동안 연구비·명성의 50%, 최대 8시간. 공사·연구 타이머는 꺼 둔 시간만큼 모두 흐릅니다. |

## 연구 컨소시엄 (함께 하기)

claude.ai에서 공유된 게임을 열면 '컨소시엄' 탭이 켜집니다. 화이트아웃 서바이벌의 연맹처럼 다른 교수들과 묶여 서로를 돕습니다.

| 기능 | 내용 |
|---|---|
| 만들기·가입 | 닉네임과 이름을 정해 만들거나, 목록에서 골라 가입합니다. 한 컨소시엄은 20명까지입니다. |
| 도움 요청 | 내 공사·연구·대학 승격은 동료 화면에 자동으로 올라갑니다. 동료가 '도와주기'를 누르면 남은 시간이 30초 또는 전체의 4% 중 큰 만큼 줄고(요청당 최대 10번), 도운 사람은 연구비 1분 치를 받습니다. |
| 공동 기술 | 연구비 10분 치를 기부하면 10점. 멤버 점수 합으로 4가지 기술(데이터 생산, 회의실, 교수실, 연구비 각 레벨당 +5%, 최대 20레벨)이 오르고 전원에게 적용됩니다. |
| 주간 공동 목표 | 멤버들이 이번 주(월요일 시작)에 쓴 논문 합이 100·500·2,000편을 넘으면 각자 상자를 엽니다. 모집권 2·3·5장과 연구비 30·60·120분 치 |
| 순위 | 멤버는 연구력(직급, 평생 명성, 월계관) 순, 컨소시엄은 멤버 연구력 합 순 |

데이터는 사람마다 `members/<내 id>` 문서 하나에만 씁니다. 컨소시엄 문서는 만든 사람의 `alliances/<id>`입니다. 기술 레벨, 받은 도움, 주간 합계는 각자 화면이 멤버 문서를 모두 읽어 계산하므로, 두 사람이 같은 문서를 동시에 고칠 일이 없습니다.

공유받은 사람이 컨소시엄에 가입하고 기부·도움을 하려면 기여자(Contributor) 이상 권한이 필요합니다. 보기 권한만 있으면 목록만 보입니다.

## 밸런스

`node sim.js` 결과입니다(첫 판). 시뮬레이터는 실제 플레이어처럼 병목 단계를 먼저 키우고, 새 방·대학 승격·싼 장비·학과 연구·연구원 배치를 함께 처리합니다. 컨소시엄 효과는 넣지 않았습니다.

| 플레이 방식 | 부교수 | 정교수 | 석학 | 세계적 명문대 | 살아있는 교과서 (엔딩) |
|---|---|---|---|---|---|
| 적극 (병목 방 독려, 이벤트 처리) | 3분 | 12분 | 41분 | 1.2시간 | 1.5시간 |
| 가벼움 (구매만) | 4분 | 13분 | 43분 | 1.5시간 | 1.7시간 |
| 4시간마다 2분 접속 | 4.0시간 | 8.1시간 | 1.2일 | 2.2일 | 2.2일 |

## 클리커 버전과 비교

| 항목 | 클리커 (대학원생 키우기) | 타이쿤 (랩실 운영하기) |
|---|---|---|
| 플레이어 | 대학원생 본인 | 조교수 → 살아있는 교과서 |
| 주된 조작 | 캐릭터 탭, 논문 쓰기 | 방 업그레이드, 병목 찾기, 학생 모집 |
| 화면 | 연구실 책상 한 장면 | 대학 본관과 3×3 아이소메트릭 연구실 |
| 첫 판 길이 (적극) | 1.1시간 | 1.5시간 |
| 함께 하기 | 랭킹 | 컨소시엄(도움·공동 기술·주간 목표) |
| 아직 없는 것 | — | 도감, 과제 목록, 상점(BM), 아바타 |

두 버전을 해 보고 방향을 정하면, 고른 쪽에 나머지 시스템을 옮겨 붙일 수 있습니다.

## QA

`node qa.js` 결과 30개가 모두 통과했습니다(2026-10-23, 크로미움). 컨소시엄은 claude.ai의 저장소를 흉내 낸 메모리 저장소로 검사했습니다.

| 묶음 | 검사 |
|---|---|
| 첫 화면 | 지방 사립대 조교수로 시작, 최종 목표 막대, 걸어 다니는 학생, 병목 표시, 폰 너비 |
| 방과 장비 | 업그레이드, 가구·장비 5종, 모습 이름, 독려, 방 선택, 잠긴 방 안내, 교수실 장비 모습 |
| 본관 | 대학 단계 5개와 승격 조건, 승격 공사, 시간이 걸리는 방 공사 |
| 성장 시스템 | 학과 연구, 일일 미션, 연구원 뽑기, 승진 모달, 엔딩과 정년 퇴임 |
| 컨소시엄 | claude.ai 밖 안내, 만들기, 동료 도움 요청 표시, 공동 기술 합산, 주간 목표, 도와주기 기록, 받은 도움으로 공사 시간 단축 |
| 공통 | 콘솔 오류 없음 |

폰 너비에서는 지도를 680px로 그리고, 지도 상자 안에서 좌우로 밀어 보게 했습니다.
