# 랩실 운영하기 · 타이쿤 프로토타입

> 교수가 되어 랩실을 운영하라

[클리커 버전](../prototype/README.md)과 비교하려고 따로 만든 두 번째 버전입니다. 클리커 버전은 대학원생 한 명을 탭해서 키우고, 이 버전은 조교수가 되어 연구실 전체를 짓고 운영합니다. 화면은 비스듬히 내려다보는 아이소메트릭 시점이고, 감옥 운영 같은 방치형 타이쿤의 구조를 따랐습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. `engine.js`가 같은 폴더에 있어야 합니다.

| 파일 | 내용 |
|---|---|
| `engine.js` | 게임 규칙 (화면과 분리, Node에서도 돌아감) |
| `index.html` | 아이소메트릭 연구실 화면과 운영 패널 |
| `sim.js` | 밸런스 시뮬레이터 (`node sim.js`) |
| `qa.js` | 브라우저 QA 11개 (`node qa.js`, Playwright 필요) |

## 핵심 구조: 세 단계 생산 흐름

```
연구 공간(실험실·서버실·클린룸·대형 장비실·국제 공동연구센터) ─데이터→ 회의실(논문화) ─논문→ 교수실(투고·과제) ─→ 연구비 + 명성
```

- 초당 처리량은 세 단계 중 가장 느린 곳이 정합니다. 화면 아래 흐름 막대와 지도의 빨간 '병목' 표시가 지금 키워야 할 곳을 알려 줍니다.
- 연구 공간은 학생이 앉아야 데이터를 만듭니다. 좌석은 방 레벨에 따라 2~10석입니다.
- 회의실과 교수실은 처리 용량이고, 승진할 때마다 1.6배가 됩니다.
- 학생은 데이터를 들고 회의실로, 논문을 들고 교수실로 걸어갑니다. 교수실에서는 연구비 동전이 튀어 오릅니다.

## 방 (3×3 부지)

| 방 | 역할 | 열리는 직급 | 공사비 |
|---|---|---|---|
| 교수실 | 투고 용량 | 조교수 | 기본 |
| 회의실 | 논문화 용량 | 조교수 | 기본 |
| 휴게실 | 학생 정원(분위기) | 조교수 | 기본 |
| 실험실 | 데이터 생산 (학생 1명당 기본 1) | 조교수 | 기본 |
| 서버실 | 데이터 생산 (기본 10) | 부교수 | 1,500 |
| 자료실 | 연구비 배율 (레벨당 +5%) | 부교수 | 3,000 |
| 클린룸 | 데이터 생산 (기본 110) | 정교수 | 20만 |
| 대형 장비실 | 데이터 생산 (기본 1,300) | 석학 | 3천만 |
| 국제 공동연구센터 | 데이터 생산 (기본 16,000) | 석학 | 6억 |

생산 공간은 레벨 10·25·50·100에서 효율이 2배가 됩니다.

## 운영 요소

| 요소 | 내용 |
|---|---|
| 학생 모집 | 연구비로 뽑습니다. 빈자리가 있어야 뽑을 수 있고, 학부연구생·석사·박사·포닥 중 무작위로 들어옵니다. |
| 연구실 분위기 | 학생이 휴게실 정원(3 + 레벨×2명)을 넘으면 1명당 7%씩 떨어집니다(최저 35%). 분위기만큼 처리량이 줄어듭니다. |
| 독려 | 방을 누르고 '독려하기'를 누르면 15초 동안 그 방이 2배가 됩니다. 방마다 45초 쿨다운입니다. |
| 돌발 이벤트 | 1.5~2.5분마다 지도 위에 뜹니다. 20초 안에 눌러서 처리합니다. 마감 임박(회의실 3배), 과제 선정(연구비 1분 치), 학회 시즌(연구비 2배), 연구비 감사(놓치면 1분 동안 교수실 절반). |
| 승진 | 명성이 쌓이면 조교수 → 부교수(1천) → 정교수(30만) → 석학(9천만) → 살아있는 교과서(270억). 승진마다 데이터 1당 연구비 ×2.5, 새 방이 열립니다. |
| 정년 퇴임 | 살아있는 교과서가 되면 황금 월계관 3개 이상을 받고 새 연구실에서 다시 시작합니다. 월계관 1개당 연구비 +25%. |
| 방치 보상 | 앱을 꺼 둔 시간 동안 연구비·명성의 50%, 최대 8시간 |

## 밸런스

`node sim.js` 결과입니다. 시뮬레이터는 실제 플레이어처럼 분위기가 떨어지면 휴게실, 새 방이 열리면 공사, 그 밖에는 병목 단계를 키웁니다.

| 플레이 방식 | 부교수 | 정교수 | 석학 | 살아있는 교과서 |
|---|---|---|---|---|
| 적극 (병목 방 독려, 이벤트 처리) | 1분 | 9분 | 26분 | 1.1시간 |
| 가벼움 (구매만) | 2분 | 9분 | 31분 | 1.4시간 |
| 4시간마다 2분 접속 | 1분 | 4.0시간 | 8.1시간 | 16.1시간 |

## 클리커 버전과 비교

| 항목 | 클리커 (대학원생 키우기) | 타이쿤 (랩실 운영하기) |
|---|---|---|
| 플레이어 | 대학원생 본인 | 조교수 → 살아있는 교과서 |
| 주된 조작 | 캐릭터 탭, 논문 쓰기 | 방 업그레이드, 병목 찾기, 학생 모집 |
| 화면 | 연구실 책상 한 장면 | 3×3 아이소메트릭 연구실 |
| 첫 판 길이 (적극) | 1.1시간 | 1.1시간 |
| 아직 없는 것 | — | 도감, 과제 목록, 상점(BM), 랭킹, 아바타 |

두 버전을 해 보고 방향을 정하면, 고른 쪽에 나머지 시스템(도감, 과제, BM, 랭킹)을 옮겨 붙일 수 있습니다.

## QA

`node qa.js` 결과 11개가 모두 통과했습니다(2026-10-23, 크로미움). 검사 항목은 다음과 같습니다.
- 첫 화면
- 걸어 다니는 학생
- 업그레이드와 독려
- 방 선택
- 잠긴 방 안내
- 병목 표시
- 폰 너비
- 후반 공사
- 승진 모달
- 콘솔 오류

폰 너비에서는 지도를 640px로 그리고, 지도 상자 안에서 좌우로 밀어 보게 했습니다.
