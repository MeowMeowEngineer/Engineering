# 랩실 운영하기 · 타이쿤 프로토타입

> 교수가 되어 랩실을 운영하라

[클리커 버전](../prototype/README.md)과 비교하려고 따로 만든 두 번째 버전입니다. 클리커 버전은 대학원생 한 명을 탭해서 키우고, 이 버전은 조교수가 되어 연구실 전체를 짓고 운영합니다. 화면은 비스듬히 내려다보는 아이소메트릭 시점입니다. 감옥 운영 같은 방치형 타이쿤의 생산 흐름에, 화이트아웃 서바이벌·클래시 오브 클랜식 성장 장치(메인 건물이 다른 건물의 한계를 정하는 구조, 공사 타이머, 학과 연구, 연구원 카드, 일일 미션, 연맹)를 붙였습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. `engine.js`가 같은 폴더에 있어야 합니다.

| 파일 | 내용 |
|---|---|
| `engine.js` | 게임 규칙 (화면과 분리, Node에서도 돌아감) |
| `index.html` | 아이소메트릭 연구실 화면과 운영 패널 |
| `sim.js` | 밸런스 시뮬레이터 (`node sim.js`) |
| `qa.js` | 브라우저·엔진 QA 59개 (`node qa.js`, Playwright 필요) |

## 핵심 구조: 세 단계 생산 흐름

```
연구 공간(실험실·서버실·클린룸·대형 장비실·국제 공동연구센터) ─데이터→ 회의실(논문화) ─논문→ 교수실(투고·과제) ─→ 연구비 + 명성
```

- 초당 처리량은 세 단계 중 가장 느린 곳이 정합니다. 화면 아래 흐름 막대와 지도의 빨간 '병목' 표시가 지금 키워야 할 곳을 알려 줍니다.
- 연구 공간은 학생이 앉아야 데이터를 만듭니다. 좌석은 방 레벨에 따라 2~10석입니다.
- 회의실과 교수실은 처리 용량이고, 승진할 때마다 1.6배가 됩니다.
- 학생은 데이터를 들고 회의실로, 논문을 들고 교수실로 걸어갑니다. 교수실에서는 연구비 동전이 튀어 오릅니다.

## 대학 본관 (메인 건물)

지도 뒤쪽의 대학 본관은 클래시 오브 클랜의 마을회관과 같은 역할을 합니다. 작은 나라 지방 소도시의 신생 대학 '한빛대'에서 시작해 한 학교를 키워 세계적 명문대로 승격시키는 것이 한 판의 최종 목표입니다.

| 단계 | 대학 | 승격 조건 | 승격 비용·시간 | 교수실 최대 레벨 | 새로 생기는 부지 |
|---|---|---|---|---|---|
| 1 | 신생 지방대 | 시작 | — | 30 | 교수실·회의실·휴게실·실험실 |
| 2 | 지역 거점대 | 부교수 | 1,000 · 1분 | 60 | 서버실·자료실 |
| 3 | 연구중심대 | 정교수 | 200만 · 3분 | 110 | 클린룸 |
| 4 | 국내 최상위 명문대 | 석학 | 30억 · 8분 | 170 | 대형 장비실 |
| 5 | 세계적 명문대 | 석학 | 3천억 · 15분 | 250 | 국제 공동연구센터 |

- 본관이 교수실의 최대 레벨을 정하고, 교수실이 다른 방의 최대 레벨(교수실 + 10)을 정합니다.
- 대학 단계가 하나 오를 때마다 명성 +15%입니다.
- 승격 공사는 방 공사와 같은 공사 대기열을 씁니다.
- 살아있는 교과서로 승진하고 대학이 세계적 명문대가 되면 엔딩입니다. 둘 중 늦게 끝나는 쪽에서 엔딩이 뜹니다.

## 방 (3×3 부지)

| 방 | 역할 | 열리는 대학 단계 | 공사비 · 공사 시간 |
|---|---|---|---|
| 교수실 | 투고 용량 | 1 | 기본 |
| 회의실 | 논문화 용량 | 1 | 기본 |
| 휴게실 | 학생 정원(분위기) | 1 | 기본 |
| 실험실 | 데이터 생산 (학생 1명당 기본 1) | 1 | 기본 |
| 서버실 | 데이터 생산 (기본 10) | 2 | 1,500 · 1분 30초 |
| 자료실 | 연구비 배율 (레벨당 +5%) | 2 | 3,000 · 2분 |
| 클린룸 | 데이터 생산 (기본 110) | 3 | 20만 · 5분 |
| 대형 장비실 | 데이터 생산 (기본 1,300) | 4 | 3천만 · 10분 |
| 국제 공동연구센터 | 데이터 생산 (기본 16,000) | 5 | 6억 · 15분 |

레벨 10·25·50·100에 닿는 업그레이드는 대공사입니다. 45초·2분·5분·10분이 걸리고, 끝나면 생산 공간의 효율이 2배가 됩니다.

## 가구·장비와 인테리어

업그레이드할수록 지도 위 모형이 단계별로 좋아집니다. 장비는 5단계, 방 인테리어는 5단계입니다.

### 장비 단계

방마다 가구와 장비가 5종 있고, 하나씩 따로 10레벨까지 올립니다. 레벨 1·3·5·8·10에서 1~5단계가 되고, 단계가 하나 오를 때마다 그 장비 효과가 10%씩 커집니다(5단계는 ×1.4). 방 카드에는 장비마다 지금 단계, 모습 이름, 지금 효과, 다음 단계까지 남은 레벨이 나옵니다.

| 방 | 가구·장비 (1단계 → 5단계) |
|---|---|
| 교수실 | 책상(합판 → 철제 → 원목 → 전동 스탠딩 → 마호가니 대가의 책상), 의자(접이식 → 가죽 중역 의자), 컴퓨터(중고 데스크톱 → 트리플 모니터 워크스테이션), 책장(철제 선반 → 저서가 꽂힌 서가), 상패 진열장(종이 명패 → 훈장 진열장) |
| 회의실 | 회의 테이블, 의자, 화이트보드(이젤 보드 → 전자 칠판), 빔프로젝터(중고 빔 → 화상회의 시스템), 커피 포트 |
| 휴게실 | 소파(낡은 소파 → 안마 소파), 커피 머신, 간식 냉장고, 낮잠 침대(간이 침대 → 호텔식 침대), 게임기(보드게임 → 아케이드 기계) |
| 실험실 | 실험대, 실험 의자, 피펫·플라스크(유리 플라스크 → 자동 분주기), 현미경(교육용 → 공초점 현미경), 흄후드(환풍기 → 안전 캐비닛) |
| 서버실 | 서버 랙, 책상과 의자, GPU(게이밍 GPU → GPU 클러스터), 냉각 장치(선풍기 → 수랭 시스템), 무정전 전원 |
| 자료실 | 서가, 열람 책상, 열람 의자, 논문 DB 구독, 스캐너 |
| 클린룸 | 방진복 보관함, 클린 벤치, 증착 장비(수동 증착기 → 원자층 증착기), 공조 설비, 측정 장비 |
| 대형 장비실 | 운영 인력석, 제어 컴퓨터, 핵심 장비(중고 장비 → 세계 유일 장비), 예약 시스템, 안전 설비 |
| 국제 공동연구센터 | 화상 회의실, 공동 서버, 통역 지원, 방문 연구원 숙소, 공유 책상 |

지도에서 보이는 변화의 예입니다.
- 의자: 단계마다 등받이가 높아지고, 3단계에 바퀴, 4단계에 머리받침, 5단계에 금색 팔걸이가 붙습니다.
- 책상: 합판색 → 철제 회색 → 원목(서랍) → 흰 전동 책상 → 금색 테두리 마호가니입니다.
- 모니터: 1대에서 2대, 3대로 늘어납니다.
- 책장·서가: 칸과 책이 늘어나고, 5단계에는 금색 저서가 꽂힙니다.
- 현미경: 커지고 색이 바뀝니다. 서버 랙은 대수가 늘고, 냉각 장치는 선풍기에서 수랭 배관으로 바뀝니다.

효과는 그 방 산출 증가, 좌석 증가(실험대·랙 등), 휴게 정원 증가, 연구비·명성 증가 중 하나입니다. 첫 두 종은 방을 지으면 바로, 나머지는 방 레벨 5·10·25에서 열립니다.

### 방 인테리어 단계

방 레벨이 오르면 바닥, 벽, 창, 조명, 소품이 바뀝니다. 모습만 바뀌고 수치는 바뀌지 않습니다.

| 단계 | 방 레벨 | 모습 |
|---|---|---|
| 1 낡은 방 | 1 | 시멘트 바닥, 빛바랜 벽과 얼룩, 작은 창 하나 |
| 2 깔끔한 방 | 10 | 타일 바닥, 흰 벽, 창문 두 개 |
| 3 아늑한 방 | 25 | 원목·카펫 바닥, 걸레받이, 액자, 화분 |
| 4 세련된 방 | 50 | 광택 바닥, 벽 패널, 간접 조명, 큰 창, 화분 둘 |
| 5 최첨단 방 | 100 | 대리석 바닥, 유리 벽, 금색 몰딩과 명판 |

## 운영 요소

| 요소 | 내용 |
|---|---|
| 학생 모집 | 연구비로 뽑습니다. 빈자리가 있어야 뽑을 수 있고, 학부연구생·석사·박사·포닥 중 무작위로 들어옵니다. |
| 연구실 분위기 | 학생이 휴게실 정원을 넘으면 1명당 7%씩 떨어집니다(최저 35%). 정원에 여유가 있으면 1명당 1%씩 올라 최대 130%가 됩니다. 분위기만큼 처리량이 바뀝니다. |
| 야식 쏘기 | 방을 누르고 '야식 쏘기'를 누르면 교수님이 피자를 시켜 15초 동안 그 방이 2배가 됩니다(휴게실은 정원, 자료실은 연구비 배율). 방마다 45초 쿨다운입니다. |
| 학과 연구 | 7갈래(실험 효율, 논문 작성법, 행정, 복지, 장학금, 공사 기술, 홍보). 연구비와 시간이 들고 한 번에 하나만 진행합니다. |
| 학생 도감 (연구원 카드) | 모집권으로 뽑는 연구원 30명. 학부연구생·석사과정·박사과정·포닥·연구교수·해외 방문연구원 5갈래이고, 등급은 일반·희귀·영웅·전설입니다. 방에 배치하면 상시 1.5~5배, 스킬을 쓰면 20~30초 동안 3~8배. 영웅 이상 없이 10번 뽑으면 다음은 영웅 이상 확정. 카드별 확률을 화면에 공개합니다. |
| 강화 | 같은 연구원이 또 나오면 중복 카드가 쌓입니다. 중복 카드를 1·2·3·5장 써서 ★2~★5로 올리고, 별 1개마다 배율 +25%. ★5에서 또 나오면 발전기금 10. 갈래를 다 모으면 세트 보너스(학부연구생 데이터 +10%, 석사과정 회의실 +10%, 박사과정 데이터 +15%, 포닥·연구교수 교수실 +15%, 해외 방문연구원 연구비 +20%) |
| 모집권 | 일일 미션, 승진, 과제 완료, 과제 선정 이벤트, 출석 7일째, 컨소시엄 주간 목표에서 무료로만 얻습니다. 결제 상품은 없습니다. |
| 일일 미션 | 업그레이드 20번, 학생 2명 모집, 야식 쏘기 5번, 이벤트 2개, 학과 연구 1번. 하나마다 모집권 1장과 연구비 5분 치, 모두 끝내면 모집권 2장 더. |
| 공사 대기열 | 시간이 걸리는 공사(새 방, 대공사, 대학 승격)는 1칸, 정교수부터 2칸 |
| 돌발 이벤트 | 1.5~2.5분마다 지도 위에 뜹니다. 20초 안에 눌러서 처리합니다. |
| 승진 | 명성이 쌓이면 조교수 → 부교수(1천) → 정교수(30만) → 석학(1.5억) → 살아있는 교과서(1,500억). 승진마다 데이터 1당 연구비 ×2.5, 회의실·교수실 용량 ×1.6, 모집권 2장 |
| 정년 퇴임 | 엔딩 뒤 황금 월계관 3개 이상을 받고 새 신생 지방대에서 다시 시작합니다. 월계관 1개당 연구비 +25%. 스타 연구원·모집권·컨소시엄은 남습니다. |
| 방치 보상 | 앱을 꺼 둔 시간 동안 연구비·명성의 50%, 최대 8시간. 공사·연구 타이머는 꺼 둔 시간만큼 모두 흐릅니다. |

## 과제

산학과제는 직급, 국가과제는 대학 단계가 되면 신청합니다. 진행 중에는 연구비가 늘고, 끝나면 그때 수입 기준 연구비와 모집권을 받습니다. 처음 마친 과제는 도감에 협약서로 남고, 25% 확률로 아바타 아이템이 나옵니다.

| 과제 | 조건 | 기간 | 진행 중 | 끝나면 | 선정률 |
|---|---|---|---|---|---|
| 산학 · 중소기업 · 시제품 성능 시험 대행 | 조교수 | 5분 | 연구비 +5% | 연구비 2분 치 | 100% |
| 산학 · 중견기업 · 공정 데이터 분석 용역 | 부교수 | 15분 | +8% | 6분 치 + 모집권 1 | 100% |
| 산학 · 대기업 · 산학 공동연구센터 | 석학 | 1시간 | +12% | 24분 치 + 모집권 2 | 100% |
| 국가 · 중소기업 주관 · 스마트 센서 국산화 | 대학 2단계 | 20분 | +10% | 13분 치 + 모집권 1 | 60% |
| 국가 · 중소기업 주관 · 친환경 소재 개발 | 대학 2단계 | 30분 | +10% | 22분 치 + 모집권 1 | 55% |
| 국가 · 중견기업 주관 · 제조 AI 고도화 | 대학 3단계 | 1시간 | +15% | 53분 치 + 모집권 2 | 45% |
| 국가 · 중견기업 주관 · 바이오 진단 키트 상용화 | 대학 3단계 | 1.5시간 | +15% | 90분 치 + 모집권 2 | 40% |
| 국가 · 대기업 주관 · 차세대 반도체 원천기술 | 대학 4단계 | 2시간 | +20% | 160분 치 + 모집권 3 | 30% |
| 국가 · 대기업 주관 · 탄소중립 에너지 플랫폼 | 대학 5단계 | 3시간 | +25% | 290분 치 + 모집권 4 | 25% |

- 신청비는 그때 수입 기준 0.5~18분 치입니다.

## 실시간 말풍선 가이드

2026-10-23 QA 피드백으로 바꾼 점: 같은 안내는 6초 유지하고, 떠다니는 말풍선은 종류마다 처음 2번과 승진·승격·새 방·퇴임 때만 띄웁니다. 가이드 줄의 실행 버튼(예: "업그레이드 · 15")으로 화면 밖 버튼도 바로 누를 수 있고, 폰에서는 가이드 줄이 화면 아래에 고정됩니다. 처음 몇 분(조교수, 업그레이드 15번 전)은 상점·뽑기보다 병목 업그레이드를 먼저 안내합니다. 병목 방이 대공사 중이면 남은 시간을 알려 주고 그동안 할 일(학과 연구·과제·장비)을 가리킵니다.

지금 가장 먼저 할 일을 하나 골라 말풍선으로 가리킵니다. 방이나 본관이 대상이면 지도 위에 말풍선과 노란 테두리가 뜨고, 버튼이나 탭이 대상이면 그 버튼이 빛나며 위에 말풍선이 뜹니다. 지도 위쪽 가이드 줄에는 자세한 설명이 나오고, 누르면 대상으로 스크롤합니다.

고르는 순서는 다음과 같습니다.
1. 엔딩 뒤 정년 퇴임, 승진, 대학 승격, 새로 열린 방 공사
2. 분위기가 떨어지면 휴게실
3. 받을 보상: 미션, 출석, 모집권, 강화할 수 있는 연구원, 빈 방에 배치할 연구원
4. 병목: 빈자리가 있으면 학생 모집, 아니면 병목 방 업그레이드. 교수실 레벨이 막으면 교수실, 교수실이 막히면 본관 승격, 자리가 꽉 차면 실험대·랙 같은 좌석 장비
5. 쉬고 있는 학과 연구, 빈 과제 칸, 싸게 올릴 수 있는 장비
6. 할 일이 없으면 다음 업그레이드까지 남은 시간

말풍선의 ×를 누르면 그 안내를 1분 동안 숨깁니다. 기록 탭에서 가이드를 끌 수 있습니다.
