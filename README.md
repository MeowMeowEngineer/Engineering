## 대표 성과

1. **IEEE Internet of Things Journal 논문 (2025, 제1저자)**: 고이득 렌즈 배열 안테나를 쓴 이중편파 분산형 FMCW 레이다로 벽 뒤 사람을 탐지. 같은 주제로 전파분야 대학원생 논문공모전 장려상. [자세히](research/README.md)
2. **LLM 연동 안테나 설계 자동화**: EM Simulator에서 손으로 하던 복잡한 3D 모델링을 LLM에 말로 지시하면 자동으로 그려지게 만들었습니다. 직접 그릴 때보다 모델링 시간을 약 OO% 줄였고, 설계와 해석을 자동으로 반복해 5일 동안 해석 1,000건 이상을 돌렸습니다. [자세히](ai-workflows/README.md)
3. **제안서·자문 7건 작성 참여**: 통신 표준, 전력선 통신, 국방, 철도, 레이다, 수중 탐지, 해외 대학 자문까지. [자세히](proposals/README.md)
4. **코트사이드 코치**: 카메라로 테니스 스윙을 분석하는 안드로이드 앱. 아이디어부터 첫 설치 파일까지 약 18분. [자세히](apps/README.md)
