## 대표 성과

1. **안테나 설계 자동화 루프**: 오프라인 CST 해석 PC와 AI 에이전트를 연결해 설계와 해석을 자동으로 반복합니다. 5일 동안 커밋 1,537개, 해석 1,000건 이상. [자세히](ai-workflows/README.md)
2. **제안서·자문 7건 작성 참여**: 통신 표준, 전력선 통신, 국방, 철도, 레이다, 수중 탐지, 해외 대학 자문까지. [자세히](proposals/README.md)
3. **코트사이드 코치**: 카메라로 테니스 스윙을 분석하는 안드로이드 앱. 아이디어부터 첫 설치 파일까지 약 18분. [자세히](apps/README.md)
