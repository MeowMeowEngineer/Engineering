## 대표 성과

1. **IEEE Internet of Things Journal 논문 (2025, 제1저자)**: 고이득 렌즈 배열 안테나를 쓴 이중편파 분산형 FMCW 레이다로 벽 뒤 사람을 탐지. 같은 주제로 전파분야 대학원생 논문공모전 장려상. [01 연구](01-research/README.md)
2. **신호처리와 하드웨어 구현에 AI 활용**: 레이다 거리 빈 선택에 머신러닝을 적용했습니다(APMC 2025). 빔포밍 시스템에서는 SPI 레벨 시프터 회로를 AI로 설계해 브레드보드로 구현했고, ADAR1000 제어 코드 작성, 아크릴 실험 지그 설계, 디버깅 로그 분석까지 AI로 했습니다. [02 AI 활용](02-ai-engineering/README.md)
3. **바이브 안테나 설계 (LLM 연동 EM Simulator)**: EM Simulator에서 손으로 하던 복잡한 3D 모델링을 LLM에 말로 지시하면 자동으로 그려지게 만들었습니다. 모델링 시간을 95% 이상 줄였고, 3D 모델링을 할 줄 모르는 사람도 안테나를 설계할 수 있습니다. 설계와 해석도 자동으로 반복해 5일 동안 해석 1,000건 이상을 돌렸습니다. [02 AI 활용](02-ai-engineering/README.md#안테나-설계-자동화-루프-비공개-연구-저장소)
4. **제안서 5건을 각 1~2일 만에 주도 작성**: 제안서 전체 흐름과 들어갈 내용을 설계하고 작성을 조율했습니다. 그림과 문구 작성에 AI를 활용해 작성 기간을 크게 줄였습니다. [03 연구 과제](03-rnd-projects/README.md)
5. **코트사이드 코치 (개인 프로젝트)**: 카메라로 테니스 스윙을 분석하는 안드로이드 앱. 아이디어부터 첫 설치 파일까지 약 18분. [04 개인 프로젝트](04-side-projects/README.md)
