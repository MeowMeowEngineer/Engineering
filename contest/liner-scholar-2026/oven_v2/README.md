# 전자레인지 모델 v2: 실제 제품 구조 반영 사양

v1(모두 PEC, 문은 금속판 하나, 초크 없음)을 실제 가정용 전자레인지 구조로 바꾼다.
기준 제품: **삼성 MS23K3513AW (국내 판매명 MS23C3513AW 계열), 23 L 단독형, 출력 800 W, 회전접시**.
선정 이유: 국내 판매 중인 23 L 보급형 단독 모델이고 내부 치수·회전접시 지름이 공개돼 있다. 국내 판매 1위라는 근거는 확인하지 못했다(가격비교 사이트 순위 미확인). 다른 모델로 바꾸려면 아래 치수 표만 바꾸면 된다.

개략도: `oven_v2_sections.png` (옆 단면, 문 실링 확대, 정면). 그림 생성: `draw_v2.py`

## 2. 구조 (v1 대비 바뀐 점)
1. **본체**: PEC → 냉연강판(손실 금속). σ ≈ 6×10⁶ S/m, μr = 1로 둠 [확인 필요]. 내부 세라믹 에나멜 코팅(약 0.1 mm)은 무시.
2. **문 (바깥 → 안쪽)**
   - 바깥 유리 4 mm: 소다석회 강화유리 εr ≈ 6.5, tanδ ≈ 0.01 → σ ≈ 0.009 S/m [확인 필요]
   - 금속 문 프레임(강판), 창 부분은 뚫려 있음
   - 타공 강판 0.3 mm, 구멍 지름 1.5 mm, 피치 2.5 mm(육각 배열) [특허 범위: 구멍 0.6~1.8 mm, 두께 0.10~0.35 mm]
   - 안쪽 PP 커버 1 mm: εr ≈ 2.3, 손실 무시
3. **초크(λ/4 쵸크)**: 문 둘레 안쪽 면에 홈. 입구 슬롯 폭 3 mm(개구 끝에서 바깥으로 8 mm 위치), 홈 깊이 약 28 mm, 접힌 폭 8 mm [특허 범위: 깊이 20~35 mm]. 입구에서 본 임피던스가 커지도록 깊이는 2.45 GHz에서 S 파라미터 또는 누설 최소가 되게 한 번 조정(스윕 24~32 mm).
4. **회전접시**: 붕규산 유리 지름 288, 두께 5, 캐비티 바닥에서 15 mm 위. εr ≈ 4.6, tanδ ≈ 0.004 → σ ≈ 0.0023 S/m [확인 필요]. 롤러는 무시.
5. **급전**: v1과 같은 WR-340 도파관 + 프로브, 캐비티 오른쪽 벽(조작부 쪽). 운모 커버(얇음)는 무시.
6. **부하**: 물 275 g(IEC 60335-2-25 누설 시험 부하), 회전접시 중앙.
7. 환기 구멍, 내부 부품(변압기, 팬)은 무시(본체 외피를 닫힌 금속으로 봄).

## 3. 타공판 처리 (메쉬 폭발 방지)
창 250 × 150 mm에 구멍이 약 6천 개라 그대로 풀면 격자가 너무 많다.
1. **단위 셀 해석**: 구멍 1개 주기 경계(Floquet), 2.45 GHz 수직 입사 → 차폐효과 SE(dB)와 위상.
2. **창을 등가 얇은 판으로 대체**: 같은 SE가 나오는 얇은 저항판(CST Thin panel 또는 Ohmic sheet).
   - 근사식 SE ≈ 20·log10(1 + Z0/(2Rs)) → 예: SE 55 dB이면 Rs ≈ 0.34 Ω/sq.
   - 타공판은 실제로는 유도성이라 위상이 다르다. 한계 절에 적는다.
3. 이 방식으로 "창으로 새는 양 vs 문 둘레로 새는 양"을 분리해 보고할 수 있다.

## 4. 해석 두 가지 모드
- **보정 모드 (v1과 같은 방식)**: 문 5 cm 평면 최대 E_rms를 13.7 V/m(정상, 0.05 mW/cm²)와 137 V/m(법정 상한, 5 mW/cm²)로 맞춘다.
- **물리 모드 (v2에서 새로 가능)**: 포트 수용 전력을 마그네트론 출력 800 W로 맞춘다. 그러면 "이 구조의 정상 제품이 실제로 얼마나 새는가"가 나온다.
  - 이 값을 법정 상한, BfS(정상 제품은 상한의 약 1%), 1973 AJPH 측정과 비교한다.
  - 문 틈 g = 0.8 / 2 / 4 mm로 "문이 헐거워지면 얼마나 늘어나나"를 본다.

## 5. 검증 항목
- 초크 효과: 같은 모델에서 초크 있음 / 없음의 5 cm 누설 비교. 통상 수십 dB 차이를 기대한다.
- 단위 셀 SE와 등가판 SE 일치.
- 누설 위치: 문 둘레(특히 모서리, 경첩 쪽)가 주 누설 경로인지 확인.

## 6. 영향 범위
- **성인 (평면파 방식)**: 1 W/m²당 SAR은 그대로 쓴다. 오븐 단독 해석만 v2로 다시 하면 된다(GPU 수 시간).
- **아동 근역장 (오븐 + 아동 5~10 cm)**: 누설 분포 모양이 바뀌므로 v2로 다시 풀어야 한다(CPU 경우당 약 17시간).
  - v1 결과는 "단순 문 vs 실제 문 구조" 민감도 비교로 남긴다.
