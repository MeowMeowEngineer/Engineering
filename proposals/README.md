# 과제·제안서

연구실에서 참여한 과제와 제안서·자문입니다. 발주처는 공개하지 않고 기관 유형으로만 적었습니다. 본문과 예산도 공개하지 않습니다.

## 내 역할

- **제안서 주도**: 제안서의 전체 흐름을 설계하고, 어떤 내용이 어떤 순서로 들어가야 하는지 정한 뒤 참여 인원의 작성을 조율했습니다 (오케스트레이션).
- **AI 활용**: 제안서에 들어가는 그림과 문구 작성에 AI를 활용했습니다.
- **속도**: 제안서 한 건을 1~2일 안에 완성했습니다.

## 1. 실제 수행 과제

### 진행 중

| 분야 | 과제 | 발주 유형 | 형태 |
|---|---|---|---|
| 전력선 통신 | DC 2선 전력선 통신(PLC) 회로 설계 자문 | 대기업 | 산학 자문 |

### 완료

| 분야 | 과제 | 발주 유형 | 형태 |
|---|---|---|---|
| 국제 협력 | 해외 대학 연구 자문 | 해외 대학 | 자문 |

## 2. 제안서 작성 경험

전체 흐름 설계부터 그림과 문구 작성까지 주도했습니다. 그림과 문구 작성에 AI를 활용해 건당 1~2일 안에 완성했습니다.

| 분야 | 과제 | 발주 유형 | 분량 | 작성 기간 |
|---|---|---|---|---|
| 이동통신 표준 | 3GPP 이동통신 표준 관련 과제 | | 쪽 | 1~2일 |
| 국방 | 국방 분야 과제 | 국가연구기관 | 쪽 | 1~2일 |
| 철도 | 도시철도차량 추진시스템 | | 쪽 | 1~2일 |
| 레이다 | 드론 탐지 레이다 | | 쪽 | 1~2일 |
| 수중 탐지 | 수중 비소나 탐지 | | 쪽 | 1~2일 |
